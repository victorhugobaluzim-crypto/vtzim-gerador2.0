AUXÍLIO VTZIM — GERADOR ONLINE COM SERVIDOR DE CHAVES

O que este projeto faz
- /gerador: painel de administrador separado visualmente do Auxílio.
- /auxilio: página que consulta o mesmo servidor para validar as chaves.
- Validades: 1 hora, 1 dia, 3 dias, 7 dias, 30 dias e permanente.
- As chaves são geradas no servidor, não são chaves de teste pré-cadastradas.
- Permite listar e revogar chaves.

IMPORTANTE SOBRE ONLINE
Este ZIP NÃO está publicado automaticamente. Para ficar online, precisa ser implantado em um host Node.js. O arquivo render.yaml prepara a implantação no Render com armazenamento persistente. Esse tipo de armazenamento pode exigir plano pago; confira o preço e as condições atuais do provedor antes de confirmar.

PASSOS MAIS FÁCEIS (pelo PC ou navegador Android)
1. Guarde este ZIP e extraia os arquivos.
2. Crie uma conta no Render e um repositório GitHub, se ainda não tiver.
3. Envie o conteúdo desta pasta para um repositório GitHub.
4. No Render, escolha New > Blueprint e conecte o repositório. O Render lê render.yaml.
5. Confira a configuração de armazenamento persistente e a variável ADMIN_PASSWORD. Defina uma senha exclusiva e forte (mínimo 16 caracteres); nunca a compartilhe nem a coloque no HTML.
6. Implante e espere o serviço ficar saudável.
7. Abra https://SEU-SERVICO.onrender.com/gerador para criar chaves e https://SEU-SERVICO.onrender.com/auxilio para validar uma delas.

NOTAS IMPORTANTES
- Não forneça a senha do administrador a usuários do Auxílio.
- Faça backup seguro do arquivo de chaves no armazenamento persistente.
- Se seu Auxílio VTZIM já está hospedado em OUTRO endereço, este pacote ainda não altera automaticamente esse site externo. O código desse Auxílio precisa chamar a API /api/validate deste servidor, com HTTPS. A página /auxilio que vem neste ZIP é uma demonstração integrada e valida as chaves deste servidor.
- Esta é uma página de validação de acesso; não modifica nem injeta recursos no Free Fire.
- O gerador só ficará acessível publicamente depois da implantação. O arquivo ZIP, sozinho, não cria um endereço online.
