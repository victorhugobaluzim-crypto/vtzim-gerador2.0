VTZIM — PUBLICAÇÃO PELO CELULAR (ANDROID)

O QUE TEM NESTE PACOTE
- server.js: servidor que cria e valida chaves.
- render.yaml: configuração para o Render.
- package.json: configuração do Node.js.
- public/: páginas do gerador e de validação.
- data/keys.json: armazenamento inicial vazio.

ATENÇÃO
1. O pacote é um serviço de chaves para um projeto próprio e não modifica o Free Fire.
2. Não publique senhas dentro dos arquivos nem as envie por mensagem.
3. O render.yaml usa disco persistente e plano Starter do Render, que pode ter custo. Confira o preço antes de confirmar.
4. O serviço ainda não está publicado; este pacote não cria uma URL sozinho.
5. A senha de administrador é gerada/configurada no painel do serviço. Use uma senha nova e exclusiva, diferente de qualquer senha compartilhada em conversas.

PUBLICAR PELO ANDROID
A. No GitHub, abra o repositório vtzim-gerador.
B. Use Add file > Upload files para enviar o CONTEÚDO desta pasta, mantendo a estrutura:
   server.js
   render.yaml
   package.json
   LEIA-ME-ANDROID.txt
   public/auxilio.html
   public/gerador.html
   data/keys.json
C. Se o seletor de arquivos do Android não permitir escolher vários arquivos/pastas, extraia este ZIP no app Arquivos e tente selecionar os arquivos extraídos. Não envie o ZIP como único arquivo: o GitHub não o extrai automaticamente.
D. Depois de enviar, toque em Commit changes.
E. No Render, escolha New > Blueprint, conecte o GitHub e selecione o repositório vtzim-gerador. O render.yaml deve estar na raiz do repositório.
F. Leia os custos e confirme a implantação apenas se aceitar o preço do plano configurado.
G. Depois que o Render terminar, abra o serviço e confira os logs. A URL pública será exibida no painel.
H. Acesse /gerador para o painel de chaves e /auxilio para validar chaves.

DICA
No GitHub mobile, o botão Add file pode ficar escondido. No Chrome, menu ⋮ > Versão para computador pode ajudar.
